나인하이어 권한 설정 가이드
평가자가 지원자를 볼 수 있도록 설정하는 방법
⚙️ 권한 설정 가이드
🔍 문제 진단
시작 전 전제 조건
평가자(현업 부서 담당자)가 먼저 워크스페이스 멤버로 초대되어 있어야 합니다.
초대가 안 되어 있으면 채용에 참여자로 추가할 수 없어요.
설정›사용자›사용자 초대
1

채용 참여자로 추가하기

평가자를 해당 채용에 참여자로 등록해요

채용 클릭› 채용 설정› 협업 설정› 내부 협업 설정
검색창에 이름 또는 이메일을 입력해 사용자를 추가하고, 채용 권한을 지정해 주세요.
채용관리자 채용 담당 HR. 채용 내 모든 설정 변경 가능. 단계 참여 여부와 무관하게 모든 지원자 열람 가능
매니저 리크루터·팀장급. 지원자 연락·합불 처리 가능. 단계 참여 + 열람 권한 "전체 사용자" or "매니저" 필요. 목적 없이 부여는 비권장
평가자 현업 부서 면접관. 서류 검토·면접 일정 확인·평가표 작성만 가능. 연락·합불 처리 불가. 단계 참여 + 열람 권한 "전체 사용자" 두 조건 모두 필요
💡
현업 부서 면접관은 보통 평가자로 설정해요. 서류 검토·평가표 작성만 필요하고 연락이나 합불 처리는 HR이 담당하니까요.
2

단계 참여 설정하기

어떤 단계에서 지원자를 볼 수 있는지 지정해요

채용 설정› 협업 설정› 참여자 목록의 '참여 단계' 드롭다운
참여자 행의 참여 단계 드롭다운을 클릭하면 단계별로 체크할 수 있어요.
기본 단계 목록
접수 · 화상 면접 · 과제 평가
직무 면접 · 컬처핏 면접
처우 협의 · 최종합격
설정 방법
모든 단계 체크 → 전체 단계 접근
개별 체크 → 해당 단계만 접근 가능
⚠️
매니저·평가자는 단계 참여가 없으면 해당 단계의 지원자 카드를 열 수 없어요. 참여해야 할 단계가 정확히 체크되어 있는지 꼭 확인하세요.
✅ 채용관리자는 단계 참여 여부와 무관하게 모든 지원자를 열람할 수 있어요.
3

권한 기본값 설정하기

신규 접수 지원자에게 자동 적용될 열람 권한을 설정해요

채용 설정› 협업 설정› 권한 기본값 설정 (하단)
세 가지 권한의 기본값을 설정해요. 평가자가 모든 정보를 볼 수 있게 하려면 모두 전체 사용자로 설정하는 게 일반적이에요.
지원자 열람 권한
신규 지원자 접수/직접 추가 시 적용
전체 사용자 권장 → 참여자라면 누구나 열람 가능
지원자 데이터 다운로드 권한
지원자 정보를 엑셀로 받아볼 수 있는 권한
필요에 따라 채용관리자로 제한 가능
평가 결과 열람 권한
평가표 추가 시 자동 적용
전체 사용자 권장 → 교차 평가 가능
⚠️
기본값은 이후에 접수되는 지원자에게만 적용됩니다.
이미 접수된 지원자는 기본값을 바꿔도 자동으로 반영되지 않아요. → 지원자 카드에서 개별 수정 필요 (하단 참고)
💡
채용을 처음 만들 때 기본값을 미리 전체 사용자로 설정해 두면, 나중에 개별 수정할 일이 줄어들어요.
+

이미 접수된 지원자의 권한 개별 수정

기본값 변경 전에 이미 들어온 지원자에게 필요할 때

지원자 관리› 지원자 카드 클릭› 상단 🔒 자물쇠 아이콘
지원자 카드 상단 제목 옆 자물쇠 아이콘(🔒)을 클릭하면 해당 지원자에게만 적용되는 권한을 개별로 바꿀 수 있어요.
변경 가능한 항목
• 지원자 열람 권한
• 지원자 데이터 다운로드 권한
선택 옵션
전체 사용자
매니저 (매니저 이상)
채용관리자
⚠️
지원자별로 개별 수정하는 방식은 시간이 많이 걸려요. 채용을 처음 세팅할 때 기본값을 미리 설정해 두는 게 훨씬 효율적이에요.

1
워크스페이스 멤버인가요?
확인 방법 ▾
나인하이어에 로그인 자체가 되지 않거나, 워크스페이스에 접근이 안 되는 경우예요.
설정 › 사용자 › 전체 사용자 목록에서 확인
목록에 없다면 사용자 초대를 먼저 진행해야 해요.
2
해당 채용의 참여자로 등록되어 있나요?
확인 방법 ▾
워크스페이스 멤버여도 채용에 참여자로 추가되지 않으면 해당 채용 자체가 보이지 않거나 지원자에 접근할 수 없어요.
채용 설정 › 협업 설정 › 내부 협업 설정
목록에 이름이 없다면 검색창에서 추가해 주세요.
3
지원자가 있는 단계에 참여 중인가요?
확인 방법 ▾
참여자로는 등록되어 있어도, 지원자가 현재 있는 단계가 참여 단계에 포함되어 있지 않으면 카드를 열 수 없어요.
채용 설정 › 협업 설정 › 참여 단계 드롭다운 확인
예: 지원자가 "직무 면접" 단계인데, 해당 평가자의 참여 단계에 "직무 면접"이 체크 안 되어 있는 경우
해결: 해당 참여자의 참여 단계 드롭다운에서 필요한 단계를 체크해 주세요.
4
지원자 열람 권한이 충분한가요?
확인 방법 ▾
1~3번이 모두 맞는데도 "지원자 열람 권한이 없습니다" 메시지가 뜬다면, 해당 지원자의 열람 권한이 평가자의 채용 권한보다 높게 설정된 경우예요.
지원자 카드 › 상단 🔒 자물쇠 아이콘
A. 기본값 설정으로 처리 (이후 접수 지원자에게만 적용)
채용 설정 › 협업 설정 › 권한 기본값 설정에서 "지원자 열람 권한"을 전체 사용자로 변경

B. 이미 접수된 지원자는 개별 수정 필요
지원자 카드 상단 자물쇠 아이콘 클릭 → 열람 권한을 전체 사용자로 변경
(기본값 변경은 이미 접수된 지원자에게 소급 적용되지 않아요)
꿀팁: 채용 초기에 기본값을 "전체 사용자"로 미리 설정해 두면 나중에 개별 수정할 일이 없어요!
1
채용 참여자로 등록되어 있나요?
확인 방법 ▾
다운로드 권한 이전에, 채용 참여자로 먼저 등록되어 있어야 해요.
채용 설정 › 협업 설정 › 내부 협업 설정
2
지원자 데이터 다운로드 권한을 확인해 주세요
확인 방법 ▾
다운로드 권한이 "채용관리자"로 설정된 경우, 매니저/평가자 권한의 참여자는 다운로드할 수 없어요.
A. 기본값 설정 변경 (이후 접수 지원자에게만 적용)
채용 설정 › 협업 설정 › 권한 기본값 설정 › "지원자 데이터 다운로드 권한"을 전체 사용자로 변경

B. 이미 접수된 지원자는 개별 수정 필요
지원자 카드 자물쇠 아이콘 → 다운로드 권한을 전체 사용자로 변경
주의: 기본값 변경은 이미 접수된 지원자에게 소급 적용되지 않아요.
1
채용 참여자로 등록되어 있나요?
확인 방법 ▾
평가 결과 열람 이전에, 채용 참여자로 먼저 등록되어 있어야 해요.
채용 설정 › 협업 설정 › 내부 협업 설정
2
평가 결과 열람 권한을 확인해 주세요
확인 방법 ▾
평가 결과 열람 권한이 "채용관리자"로 설정된 경우, 매니저 이하 권한에서는 타인의 평가 결과를 볼 수 없어요.
채용 설정 › 협업 설정 › 권한 기본값 설정 › 평가 결과 열람 권한
기본값을 전체 사용자로 변경하면 이후 추가되는 평가표부터 전체 참여자가 열람할 수 있어요.
이미 추가된 평가표는 개별 수정이 필요합니다.
주의: 기본값 변경은 이미 접수된 지원자에게 소급 적용되지 않아요.
3
평가표가 아직 제출 전은 아닌가요?
확인 방법 ▾
평가표가 "평가 중" 상태(제출 전)인 경우, 다른 참여자가 결과를 볼 수 없어요.
평가자가 평가표를 제출 완료해야 결과가 공유됩니다.
평가표 마감일이 지나면 자동으로 제출 처리되기도 해요.
